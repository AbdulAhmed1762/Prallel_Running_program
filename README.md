# Parallel Racing Simulation

## Overview
A Java-based parallel racing simulation that demonstrates multithreading, synchronization, and concurrent programming concepts. The program simulates 16 racers crossing multiple ropes while coordinating thread execution and shared resources.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Multithreading and Concurrency
- Thread Synchronization
- Locks and Semaphores

## Features
- Simulates 16 racers using individual Java threads.
- Manages three rope-crossing sections with multiple threads.
- Uses synchronization mechanisms to coordinate racers and prevent race conditions.
- Implements team coordination and midpoint synchronization.
- Demonstrates thread management and concurrent execution.

## Project Structure
- `Racer.java` — Represents individual racers and their execution.
- `RopeCrossing.java` — Manages rope-crossing operations.
- `Team.java` — Handles team coordination and synchronization.
- `RaceSimulation.java` — Initializes and runs the simulation.

## Purpose
Developed as part of a Parallel Programming course at Mohawk College to apply Java concurrency concepts and gain practical experience managing multiple threads.
